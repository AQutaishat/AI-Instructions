# Progress Log

Chronological record of work that actually happened.

Do not pre-fill with roadmap items.

## Entry format

```text
## YYYY-MM-DD — topic

- What was implemented.
- Files/modules materially changed.
- Technical decisions.
- Tests/checks actually run.
- Results.
- Bugs/blockers.
- Resolution or remaining issue.
- Important handoff context.
```
