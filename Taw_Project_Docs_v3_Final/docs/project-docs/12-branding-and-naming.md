# Taw — Branding and Naming History

## Naming goal

The brand name should not be tightly tied to water because the company/product architecture may support other delivery categories in the distant future.

However, the **current product UI remains water-only**.

The naming requirement therefore became:

- Short.
- Easy in Arabic.
- Easy enough in English.
- Feels fast/immediate/local.
- Not literally "water".
- Can work as product identity and domain.

## Names explored

Examples explored in discussion included:

- Wasel / واصل.
- Wasla / وصلة.
- Wassal / وصّال.
- Waslak / وصلك.
- Qorbak / قربك.
- Wared / وارد.
- Jehtak / جهتك.
- Laindak / لعندك.
- Hader / حاضر.
- Yalla / يلا.
- Tamm / تم.
- Taw / توّ.

## Why several names were rejected

### Wasel / واصل

Strong meaning but crowded in Jordan/Saudi Arabia and closely associated with delivery/business products.

### Yalla / يلا

Excellent energy and memorability, but extremely crowded as an app/company name across the region.

### Hader / حاضر

Excellent service meaning but already heavily used, including service/delivery contexts.

### Tamm / تم

Short and meaningful, but already widely used commercially in Saudi Arabia and elsewhere.

## Dialect inspiration

The naming discussion also explored colloquial phrases meaning roughly:

- "هيني جايك"
- "شوي وبكون عندك"
- "بطرفة عين"
- "رمشة"
- "هسّا"
- Gulf/colloquial use of "توّ" / "توّه" to convey immediacy/recentness.

The goal was a brand with the *feeling* of "now / coming / almost there" rather than a literal logistics name.

## Current working brand — Taw / توّ

The current preferred name is:

> **Taw / توّ**

Reasons:

- Very short.
- Memorable.
- Does not lock the identity to water.
- Can imply immediacy in Gulf/Arabic usage.
- Works well visually as a simple app identity.

## Collision research

Research found an existing Gulf tech/finance product using **Taw · توّ**, so the name is not globally empty. The project owner accepted that conflict as sufficiently distant from Taw's intended water-delivery SaaS context.

Therefore the brand remains a working choice, but formal trademark/domain checks should still happen before major public launch or paid branding spend.

## Domain direction

A delivery-specific TLD was considered attractive because the base brand is general.

Current candidate:

> `taw.delivery`

Benefits:

- Explains the product category without changing the brand.
- Still works if Taw delivers categories beyond water later.
- Cleaner conceptually than forcing "water" into the brand name.

Registrar availability must be checked directly before purchase.

## Icon direction

Several water-inspired icon concepts were explored.

Final design direction from discussion:

- Simple.
- Closer to flat vector.
- Blue/cyan water palette.
- Avoid glossy/3D effects.
- Water droplet/flow motif is acceptable.
- Can integrate the Arabic brand mark subtly.
- Must remain legible as a small app icon.

## Brand architecture rule

Even though the brand is general, public product messaging should clearly state the current use case, for example:

> Taw — منصة طلب وإدارة توصيل المياه

Do not present users with a generic multi-industry system today.
